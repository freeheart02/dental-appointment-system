
# 口腔诊所患者预约登记软件开发计划

## 一、项目概述

本项目是为口腔诊所开发的患者预约登记软件，旨在提高诊所运营效率，优化患者就诊体验。

### 核心功能需求

根据用户需求分析，本软件包含以下核心模块：

| 模块 | 功能描述 |
|------|----------|
| 用户认证 | 患者电话号码实名认证 |
| 患者管理 | 患者信息登记、查询、编辑 |
| 预约登记 | 患者选择医生和时间进行预约 |
| 医生排班 | 诊所端管理医生排班和放号 |
| 预约查询 | 患者和诊所端均可查询预约记录 |
| 数据统计 | 后台统计患者爽约情况等数据 |

### 技术架构

- **前端框架**: Vue 3 + Vite
- **后端框架**: Node.js + Express
- **数据库**: MongoDB
- **UI样式**: TailwindCSS 3
- **状态管理**: Pinia
- **路由**: Vue Router
- **认证**: JWT Token

## 二、功能模块详细设计

### 2.1 用户认证模块

**患者端：**
- 手机号码输入
- 短信验证码获取与验证
- 实名认证通过后进入预约流程

**诊所端：**
- 管理员账号密码登录
- 会话管理

### 2.2 患者管理模块

- 患者信息记录（姓名、电话、性别、年龄、就诊记录）
- 患者信息查询（按姓名、电话搜索）
- 患者信息编辑与删除

### 2.3 预约登记模块

- 选择医生
- 选择预约日期和时间段
- 填写就诊类型（如：洗牙、补牙、拔牙等）
- 确认预约信息

### 2.4 医生排班模块

- 医生信息管理（姓名、专业、简介）
- 排班设置（日期、时间段、放号数量）
- 排班查询与编辑

### 2.5 预约查询模块

**患者端：**
- 查看个人预约记录
- 取消预约

**诊所端：**
- 查看所有预约记录
- 按条件筛选（医生、日期、状态）
- 标记就诊状态（已到诊、爽约、取消）

### 2.6 数据统计模块

- 爽约率统计
- 预约趋势图表
- 医生工作量统计

## 四、API接口设计

### 4.1 认证接口

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/auth/send-code | POST | 发送验证码 |
| /api/auth/verify-code | POST | 验证验证码（患者登录） |
| /api/auth/admin/login | POST | 管理员登录 |

### 4.2 患者接口

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/patients | GET | 获取患者列表 |
| /api/patients/:id | GET | 获取患者详情 |
| /api/patients | POST | 创建患者 |
| /api/patients/:id | PUT | 更新患者 |
| /api/patients/:id | DELETE | 删除患者 |

### 4.3 医生接口

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/doctors | GET | 获取医生列表 |
| /api/doctors/:id | GET | 获取医生详情 |
| /api/doctors | POST | 创建医生 |
| /api/doctors/:id | PUT | 更新医生 |
| /api/doctors/:id | DELETE | 删除医生 |

### 4.4 排班接口

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/schedules | GET | 获取排班列表 |
| /api/schedules/doctor/:doctorId | GET | 获取指定医生排班 |
| /api/schedules | POST | 创建排班 |
| /api/schedules/:id | PUT | 更新排班 |
| /api/schedules/:id | DELETE | 删除排班 |

### 4.5 预约接口

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/appointments | GET | 获取预约列表 |
| /api/appointments/patient/:patientId | GET | 获取患者预约 |
| /api/appointments | POST | 创建预约 |
| /api/appointments/:id | PUT | 更新预约状态 |
| /api/appointments/:id | DELETE | 取消预约 |

### 4.6 统计接口

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/statistics/no-show-rate | GET | 获取爽约率统计 |

## 九、安全考虑

1. **密码安全**: 使用 bcrypt 加密存储密码
2. **JWT认证**: 使用 JWT Token 进行接口认证
3. **短信验证码**: 使用阿里云/腾讯云短信服务，设置验证码有效期
4. **数据验证**: 前端和后端双重验证用户输入
5. **HTTPS**: 生产环境使用 HTTPS 协议
